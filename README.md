# DEX Keyboard

Android IME keyboard designed for Samsung DeX.

Features:
- English QWERTY
- Bulgarian phonetic QWERTY
- floating/resizable IME window support
- move and resize controls
- Android 7.0+ (API 24)
- target SDK 35

## APK

The debug APK is generated by GitHub Actions and is available under the **Actions** tab as the workflow artifact `dex-keyboard-debug`.

The locally validated build has passed:
- `gradle clean test`
- `gradle assembleDebug`
- APK signature verification (v2)
