# DEX Keyboard

Android IME keyboard designed for Samsung DeX.

Features:
- English QWERTY
- Bulgarian phonetic QWERTY
- floating/resizable IME window support
- move and resize controls
- Android 7.0+ (API 24)
- target SDK 28

## APK

The project is built by GitHub Actions.
